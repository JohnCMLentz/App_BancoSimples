# App Banco Simples

Aplicação em Console desenvolvida em C# como projeto de estudo para praticar Programação Orientada a Objetos, manipulação de arquivos e lógica de programação.

## Objetivo

Desenvolver um sistema bancário simples para consolidar conhecimentos em C#, aplicando conceitos como:

- Programação Orientada a Objetos (POO)
- Classes e Objetos
- Encapsulamento
- Manipulação de arquivos (.txt)
- Estruturas de decisão
- Estruturas de repetição
- Métodos
- Coleções

## Funcionalidades

- Criar conta
- Login utilizando código e senha
- Consultar saldo
- Realizar depósito
- Realizar saque
- Transferir dinheiro entre contas
- Persistência dos dados utilizando arquivos `.txt`

## Tecnologias

- C#
- .NET
- Aplicação Console
- Manipulação de Arquivos (System.IO)

## Estrutura dos dados

As contas são armazenadas em um arquivo `.txt`, onde cada linha representa uma conta.

Exemplo:

João;1234;123456;1500.50
